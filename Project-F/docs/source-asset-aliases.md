# Original asset addressing restoration

The original public config paths, frame UUIDs, packed texture rectangles, rotation, trim size/offset, mesh metadata and9-slice borders are recorded in source-asset-alias-manifest.json with source hashes. Original pixels are reused. No images are generated, cut or copied and no language is substituted.

The bootstrap layer creates native SpriteFrame/SpriteAtlas objects from that exact metadata and real Texture2D assets. It preserves original frame UUIDs in the runtime cache. Source opaque texture IDs remain explicit. Creator3.8.8 can automatically replace an invalid9-character image/subasset metadata ID on first import. The recorded metadata UUID is an inventory snapshot; the runtime resolves the current physical Texture2D/ImageAsset through its native bundle/path and records the actual legal ID. Original dependency IDs use identity views over that same real asset/GPU/refcount, without duplicating pixels/GPU textures or changing the live physical asset UUID. The alias layer itself does not write image metadata; this bounded first-import remapping is performed by Creator. Their existing shared/images folder is declared sourcePackedImages for explicit inclusion in official builds; only its bundle ownership setting changes.

Dynamic Bundle path/directory lookup preserves original config order, typed lookup and slash boundaries. Engine dependency loading is prepared before native preprocess. Creator can discard unknown prefab references while building; the layer restores only source-proven component fileId/property and instance-override references after native deserialization, before the caller can instantiate/activate the asset. The alias layer does not modify source prefab/scene files or their UUIDs. Other source-backed compatibility repairs are recorded separately; this is not a project-wide claim that no prefab was repaired. Frames are packable=false to preserve original packed layout. Native reset(sourceInfo,true) clears the transient stale rotation before texture validation, then reapplies the exact source rotation/rect/trim/borders.

Runtime implementation: assets/shared/bootstrap/source-asset-aliases.ts. Compact runtime data: source-asset-alias-manifest.ts. The template is maintained under tools/recovery/templates; there are no cross-project runtime imports. To regenerate only compact data from the public provenance manifest, run `node tools/recovery/emit-source-asset-alias-data.mjs Project-F` from the collection root. Preserve the existing script.meta when updating.

Own hidden DOM #SourceAssetAliasesAudit records a bounded100-entry loading/repair audit. This layer restores frontend assets only and makes no claim about original backend/RNG/RTP. Static source/geometry oracles and mocked native-boundary tests do not replace official Creator build and browser visual/input/audio acceptance.
