# Project-A

可單獨匯入 Cocos Dashboard 的 Creator3.8.8 專案。

- 匯入本資料夾，請勿匯入集合根目錄。
- `assets/scenes/`：入口場景。
- `assets/game/content/`：本遊戲原始素材與 Prefab。
- `assets/game/scripts/`：本遊戲還原程式。
- `assets/game/backend/`：自有模擬後端，非原始伺服器。
- `assets/shared/`：此專案隨附的公共框架。
- 匯入 `build-config.json`，使用官方 GUI 建置至 `build/web`。
- 雙擊 `開啟本遊戲預覽.command` 開啟已建置成品；不會自動編譯。

開發測試加 `reaDevelopmentMute=1`；一般預覽保留正常聲音。
