# 還原狀態與驗收界線

## 已觀察與已驗證

- 來源客戶端為 Cocos 3.7.2發布包，本工程使用官方 Creator 3.8.8重新整理的場景、Prefab、圖片、音效、Spine及腳本。
- 2026-11-04在 Creator 原生瀏覽器預覽中，`mainPortrait` 進入開始畫面與主盤面；透過畫面按鈕連續兩局，均觀察到 `spin`、`closeSpin` 及下一局可操作。
- 當日修復缺少 `gn` 導致載入不存在的 `g1001`；改由獨立 bootstrap 補入賽特2的啟動參數。保留使用者明確提供的參數。
- 契約測試以實際自有後端程式驗證一般／免費／覺醒／三種購買、彩金、倍率、分裂、鎖定、持久化續局與單次結算；不以回合樣本輪播代替盤面生成。
- 本次啟動修正的實際截圖、普通回合紀錄與限制見 [evidence/verification.json](evidence/verification.json) 和 [Creator 實測畫面](evidence/creator-play.png)。這些證據是在獨立移倉前的同一份遊戲內容上取得；移倉後的檢查另記錄於 migration-verification.json。

- 搬移後重現快速停輪將回收的 inactive 符號卡住，已補上 Node tween 相容設定；回歸測試重現修正前不觸發完成、修正後30格完成一次。實際 UI 驗證範圍另記 migration-verification.json。

## 本機假設

公開顯示賠率／購買倍數與前端可讀欄位是契約依據；初始參數、機率、權重、倍率分布、鎖定與分裂策略、彩金池規則及部分特殊模式邊界為自行實作。詳細說明見 `assets/local-backend/FeatureRules.md`。修改它們不代表還原原廠機率。

## 未保證項目

- 原廠伺服器、RNG、RTP及帳務安全未還原；本地點數不是真實帳戶。
- 本次搬移不構成重新窮舉所有免費、覺醒、購買與彩金動畫路線的驗收。
- 部分原 Spine 資料為3.7.94，Creator 3.8 runtime 可能印出相容性警告；不保證所有原動畫無差異。
- 多分頁同時操作同一個 localStorage 錢包未作正式交易安全驗證。
- 原版的完整歷史報表、原站大廳、正式服務管理與原廠熱更新不在此工程的承諾範圍。
- 部分素材有重名資源的匯入警告；不得以清除正式素材或停用原遮罩來宣稱修復。

編輯器能開啟、測試通過或建置檔存在，都不能單獨證明完整遊戲還原成功。
